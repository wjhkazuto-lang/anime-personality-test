# 动漫人格测试

固定36题，约5—7分钟，80位角色、40部作品，全部有本地头像与带图分享。以AniList累计角色收藏数为主选角，并保留用户点名角色及作品方向；热度不进入匹配分数。

有效回答足够后，始终给出一位“这次最接近你的角色”。相近角色默认折叠，分享图只突出主角色。倾向均衡、差异较大、角色依据不足或同分会有简短提示。首选是现有编辑坐标中距离最近的一位，不等于唯一人格归属或已验证的准确率。同分按稳定的数据顺序选首位，没有随机换人。

每维至少4个有效回答；没经历过不作中间分。有效回答不足时提示返回补答。旧回答按题目ID沿用，答案仅保存在当前浏览器。

金木研取√A白发阶段并采用官方头像，角色解读保留其阶段、反例与未知维度。完整300位原资料在维护者本地备份保存。图像版权归原权利方，来源见关于页。

纯静态网页；GitHub Pages使用main分支根目录。发布包含全部运行脚本和当前80张图片。
